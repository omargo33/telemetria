# Telemetria

Aplicacion de telemetría para implementar telemetria en aplicaciones JAVA y la creación de anotaciones personalizadas para la recopilación de datos de telemetría.

## Características/features

### Versión 0.0.1

- Implementación de anotaciones personalizadas para la recopilación de datos de telemetría.
- Recopilación de datos de telemetría en tiempo real.
- Test de arquitectura de servidores para la recopilación y procesamiento de datos de telemetría.

# Configuración de desarrollo

## JDK (JAVA Development Kit)

El sistema debe tener instalado el JDK (JAVA Development Kit) en su versión 17, para verificar la versión de java se debe ejecutar el siguiente comando:

```bash
java -version
```

## Maven

El sistema debe tener instalado Maven, al menos la versión 3.5.0 para verificar la versión de Maven se debe ejecutar el siguiente comando:

```bash
mvn -version
```

Para ejecutar la aplicación, se debe ejecutar el siguiente comando en la terminal:

```bash
mvn spring-boot:run
```

>**NOTA:** 
>
>Los log del producto se obtienen de manera estándar en la consola de la aplicación.
